使用须知
  1. 必须选中本应用：设置 → 开发者选项 → 选择模拟位置信息应用 → Tsursport。换版本或重启后可能被清空，每次跑前确认。
  2. 电池设为不受限制：应用信息 → 电池 → 不受限制；关闭「深度休眠」「自动优化」，否则后台服务被停，位置会跳回真实值。
  3. 建议关闭 WiFi：地图/定位 SDK 会用 WiFi 指纹反查真实位置，用移动数据更稳。
  4. 定位总开关保持高精度，并允许本应用「身体活动」权限，否则读不到步频。
  5. 先强停目标 App（如支付宝）→ 开 Tsursport 开始模拟 → 再打开目标 App，避免它沿用缓存定位。
  6. 步频用「跟随步频」：步幅 = 身高cm × 0.45。走路 100–130 spm、慢跑 150–175 spm，配速自然落在 5'30"–8'00"。
  7. 人必须真的在动：静止时步频为 0，会被判定「配速异常 / 无运动」。
  8. 路线别是完美直线：多点、有拐弯；速度已带 ±8% 自然抖动。
  9. 留在电子围栏内，出圈里程不计；时段按学校规定（多为 6:00–22:00）。
  10. 不要一台设备切多账号，平台按作弊处理。
  11. 技术边界：位置可伪造，isMock 标记、WiFi/基站、卫星、步频读数、设备指纹 免 root 改不了；平台若深度校验仍可能判无效，且会回溯复核历史记录。
